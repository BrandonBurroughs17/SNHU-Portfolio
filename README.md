# CS 405: Secure Coding

## Overview

This repository branch contains my coursework and projects from CS 405: Secure Coding at Southern New Hampshire University (SNHU), completed as part of my Bachelor of Science in Computer Science with a concentration in Software Engineering.

Throughout this course, I explored common software vulnerabilities, secure coding practices, and methods for identifying and preventing security risks. The primary focus was learning how to incorporate security throughout the software development lifecycle rather than treating it as something to address after development is complete.

## Topics Covered

- **Secure Coding Standards:** Applying established coding practices to reduce vulnerabilities and improve software reliability.
- **Buffer Overflows:** Understanding memory-related vulnerabilities and implementing safeguards to prevent unauthorized memory access.
- **Integer Overflow and Underflow:** Identifying arithmetic vulnerabilities and implementing input validation and boundary checks.
- **SQL Injection:** Examining database security vulnerabilities and techniques for preventing malicious queries.
- **Exception Handling:** Developing strategies for handling unexpected conditions without exposing sensitive information.
- **Unit Testing:** Creating and evaluating tests to verify application behavior and identify potential security issues.
- **Encryption:** Exploring cryptographic techniques used to protect sensitive data.
- **Static Code Analysis:** Using tools such as Cppcheck to identify potential vulnerabilities and coding errors.
- **Zero Trust Security:** Understanding the importance of verifying access rather than automatically trusting users or devices.

## Projects and Assignments

### Secure Coding Activities
Completed programming exercises focused on identifying vulnerabilities, understanding their causes, and implementing safer coding practices.

### Security Policy Development
Developed security policies and implementation recommendations for the fictional Green Pace organization. This work focused on establishing consistent coding standards, evaluating risks, and creating guidelines for maintaining secure software development practices.

### Security Testing and Analysis
Explored techniques for evaluating code security through unit testing, vulnerability assessment, and static code analysis.

## Key Takeaways

One of the biggest lessons I learned throughout CS 405 was that writing functional code does not necessarily mean writing secure code. Even small mistakes involving memory management, input validation, or error handling can introduce vulnerabilities.

This course helped me develop a more security-focused approach to software development. I gained experience recognizing potential vulnerabilities, evaluating their risks, and implementing practices that help prevent them.

As I continue pursuing a career in software engineering, particularly embedded software development, these skills will be important when developing reliable and secure systems.
